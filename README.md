# Jarvis Portátil

Projeto para combinar um assistente de voz local no Windows com uma interface controlada por gestos da webcam.

## Projetos de referência

- [Jarvis](https://github.com/isair/jarvis) para voz, chat e memória local com Ollama.
- [H.O.L.O Hands](https://github.com/zubair-trabzada/holo-gestures) para interagir com cartões e objetos 3D por gestos.

## Primeiro protótipo

Abrir um cartão com uma pinça dupla e enviar o texto ao assistente por uma ligação local. O Jarvis lê ou resume a nota em voz alta.

Este repositório está na fase inicial. A integração ainda precisa de ser implementada.
